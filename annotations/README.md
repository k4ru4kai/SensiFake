# Annotazioni e risultati

Le cartelle e i file storici restano ai percorsi attuali. Non sono stati spostati
per anticipare il workflow pianificato.

La struttura prevista è descritta nella [guida annotazione](../docs/annotation.md):
`master/` per lo stato SQLite autorevole, `packages/outgoing/` e
`packages/returned/` per lo scambio offline, `exports/` per gli export CSV e
`archive/legacy/` per artefatti storici dopo una migrazione esplicita.
