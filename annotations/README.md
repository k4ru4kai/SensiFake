# Annotazioni e risultati

`master/` contiene lo stato SQLite autorevole. `packages/outgoing/` e
`packages/returned/` contengono snapshot di revisione emessi e restituiti.
`exports/` contiene export CSV. I file storici restano nei percorsi esistenti;
`archive/legacy/` è riservato a un futuro archivio esplicito.

Vedere la [guida annotazione](../docs/annotation.md).
