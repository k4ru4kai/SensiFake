# Historical research notebooks

The existing public VLM notebooks remain under `notebooks/` as source-only
historical evidence. Outputs, execution counters and machine metadata were
removed for privacy; source conversions are recorded in `docs/import_catalog.json`.
No notebook is designated final scientific authority. Newly imported detector
and autoannotation notebooks are withheld pending publication permission; see
`docs/DEFERRED_SOURCE.md`. Originals remain untouched in their working repositories.

Use `notebooks/sensifake_quickstart.ipynb` for the supported v0.1 entrypoints.
